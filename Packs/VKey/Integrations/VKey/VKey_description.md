### Overview
Integrates with the **V-Key V-OS BSI (Business Security Intelligence)** API Gateway to continuously pull mobile runtime security threats, device hardware profiles, and application package integrity telemetry into Cortex XSIAM.

### Prerequisites
1. **V-Key Tenant APIM URL** (e.g. `https://stg-apim-public.azure-api.net/bsi`).
2. **APIM Subscription Key** (`Ocp-Apim-Subscription-Key`).
3. Outbound HTTPS (Port 443) network access.
